# Platform overview

One shared platform runs every brand, from the menu to the doorstep. The picture of what is being built for a manager is the SHLD. This folder also has a system overview for the technical reading of that same platform.

## Diagrams

**Overview** — `mfg-eplatform-overview.drawio`

Sign in, checkout, the kitchen and the rider, and telling the customer. A solid line is someone asking. A dashed line is Kafka. Not a replacement for the SHLD. The rulebook is [`overview-guideline.md`](../overview-guideline.md).

**SHLD** — `mfg-eplatform-shld.drawio`

Who uses the platform, what it can do, who it depends on, and how one order runs.

**HLD** — `mfg-eplatform-hld.drawio`

The drifted container picture. [`architecture.md`](../architecture.md) wins where they disagree.
